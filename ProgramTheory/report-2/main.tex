\section*{問題}

$N$ を $M$ または $M_{\text{tot}}$ とする。

$s$、$t$ を状態（適切な状態、$\bot$ ではない）とする。このとき以下を証明せよ。

\begin{enumerate}
    \item $t \in N\llbracket S \rrbracket (s)$ ならば $t[\text{Var} - \text{change}(S)] = s[\text{Var} - \text{change}(S)]$。
    \item $s[\text{var}(S)] = t[\text{var}(S)]$ ならば $N\llbracket S \rrbracket (s) = N\llbracket S \rrbracket (t) \mod (\text{Var} - \text{var}(S))$。
\end{enumerate}

\section*{解答}

\subsection*{はじめに}

\begin{itemize}
    \item $\text{Var}$：すべての変数の集合。
    \item $\text{change}(S)$：プログラム $S$ によって値が変更される可能性のある変数の集合。
    \item $\text{var}(S)$：プログラム $S$ に出現する変数の集合。
    \item $s[Z]$：状態 $s$ を変数集合 $Z$ に制限した（射影した）状態。
    \item $X = Y \mod Z$：集合 $X$ と $Y$ の各状態が、変数集合 $\text{Var} - Z$ において同じであることを意味する。
\end{itemize}

\subsection*{問題1の証明}

\textbf{命題}：

もし $t \in N\llbracket S \rrbracket (s)$ ならば、$t[\text{Var} - \text{change}(S)] = s[\text{Var} - \text{change}(S)]$。

\textbf{証明}：

\begin{enumerate}
    \item $t \in N\llbracket S \rrbracket (s)$ である。

    つまり、状態 $s$ からプログラム $S$ を実行して、状態 $t$ に到達する。

    \item プログラム $S$ は $\text{change}(S)$ に含まれる変数のみを変更する。

    \item よって、$\text{Var} - \text{change}(S)$ に属する変数の値は実行前後で変化しない。

    すなわち、
    \[
    t[\text{Var} - \text{change}(S)] = s[\text{Var} - \text{change}(S)]。
    \]

\end{enumerate}

\textbf{結論}：

したがって、$t \in N\llbracket S \rrbracket (s)$ ならば、$t$ と $s$ は $\text{Var} - \text{change}(S)$ に属する変数について同じ値を持つ。

\vspace{1em}

\subsection*{問題2の証明}

\textbf{命題}：

もし $s[\text{var}(S)] = t[\text{var}(S)]$ ならば、$N\llbracket S \rrbracket (s) = N\llbracket S \rrbracket (t) \mod (\text{Var} - \text{var}(S))$。

\textbf{証明}：

\begin{enumerate}
    \item 状態 $s$ と $t$ は、$\text{var}(S)$ に属する変数について同じ値を持つ。

    \item プログラム $S$ は $\text{var}(S)$ に含まれる変数のみを参照する。

    \item よって、$S$ の実行において、$s$ と $t$ の違いは影響しない。

    \item したがって、$N\llbracket S \rrbracket (s)$ と $N\llbracket S \rrbracket (t)$ は、$\text{Var} - \text{var}(S)$ に属する変数を除けば同じである。

    すなわち、
    \[
    N\llbracket S \rrbracket (s) = N\llbracket S \rrbracket (t) \mod (\text{Var} - \text{var}(S))。
    \]

\end{enumerate}

\textbf{結論}：

したがって、$s[\text{var}(S)] = t[\text{var}(S)]$ ならば、$N\llbracket S \rrbracket (s)$ と $N\llbracket S \rrbracket (t)$ は $\text{Var} - \text{var}(S)$ において同じである。

\vspace{1em}

\subsection*{補足：具体例による説明}

\subsubsection*{問題1の具体例}

\begin{itemize}
    \item \textbf{プログラム $S$}：$x := x + 1$。
    \item $\text{change}(S) = \{ x \}$。
    \item 状態 $s$：$x = 1$, $y = 2$。
    \item 状態 $t$：$x = 2$, $y = 2$（$s$ から $S$ を実行した結果）。
    \item \textbf{確認}：$\text{Var} - \text{change}(S) = \{ y \}$ について、$t[y] = s[y]$。
\end{itemize}

\subsubsection*{問題2の具体例}

\begin{itemize}
    \item \textbf{プログラム $S$}：$z := x + y$。
    \item $\text{var}(S) = \{ x, y \}$。
    \item 状態 $s$：$x = 1$, $y = 2$, $w = 3$。
    \item 状態 $t$：$x = 1$, $y = 2$, $w = 4$。
    \item \textbf{確認}：$s[\text{var}(S)] = t[\text{var}(S)]$。$w$ の値は異なるが、$S$ の実行結果に影響しない。
    \item $\text{Var} - \text{var}(S) = \{ w \}$。$N\llbracket S \rrbracket (s)$ と $N\llbracket S \rrbracket (t)$ は $w$ を除けば同じである。
\end{itemize}

\subsection*{結論}

これらの問題は、プログラムの実行が変数に与える影響を形式的に表現しています。

\begin{itemize}
    \item \textbf{問題1}：$S$ によって変更されない変数の値は、実行前後で変化しない。
    \item \textbf{問題2}：$S$ が参照しない変数の値が異なっていても、$S$ の実行結果はそれらの変数を除けば同じ。
\end{itemize}

上記の性質は、プログラムの正当性を証明する際に重要です。
